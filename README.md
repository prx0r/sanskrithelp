# Prakriyā Wheel — sanskrit.help

Sanskrit noun declension, taught as a machine rather than a table.

**Live:** https://sanskrit.help

## What this is

Five colours, five grammatical jobs, applied in a fixed order:

```
rūpa = saṃskāra( pratyaya( gaṇa( aṅga ) ) )
```

| Colour | Layer | Job |
|---|---|---|
| blue | aṅga | the stem you picked |
| green | gaṇa | its family and gender |
| amber | pratyaya | the sup ending for case × number |
| purple | saṃskāra | the rule that transforms |
| teal | rūpa | the finished word |
| grey | saṃjñā | grammar naming things |
| red | blocked | a slot the engine would not fill |

Nothing on the site is typed from memory. Every surface form and every
derivation step is generated by **Vidyut 0.4.0** (Ambuda project, MIT) from the
Aṣṭādhyāyī rule inventory, and every step row shows the sūtra the engine fired.

## Coverage

- 57 stems
- 17 declension families
- 1,368 forms (57 × 8 cases × 3 numbers), all `DERIVED`
- 341 syncretic surfaces (one form, several analyses) used for the reverse game

Families: a-masc, a-neut, ā-fem, ī-fem, ū-fem, i-masc, i-neut, u-masc, u-neut,
ṛ-agent, an-masc, c-fem, as-neut, in-masc, ant-masc, vant-masc, diphthong.

## Honesty rules

- **DERIVED ≠ truth.** A derivation is a computation, not a scholarly reading.
- **BLOCKED ≠ PASS.** A slot with no derivation renders as blocked, never as a guess.
- **Disagreements are recorded.** Hand-curated reference tables are cross-checked
  against the engine at build time; the current run agrees **72/72** slots exactly.
  Any disagreement is written into `public/data/index.json`, never silently fixed.
- No auto-publish, no auto-sign, no promoted claims.

## Sūtra text

Vidyut's rule inventory has no word division ("vfdDirAdEc"). The citation text
shown under each code comes from the community *padaccheda* edition
([sanskrit/ashtadhyayi](https://github.com/sanskrit/ashtadhyayi)), cleaned of
editorial markup and transliterated to IAST by `tools/fetch_sutras.py`.
2,561 of 3,983 sūtras carry word division in that edition; the rest are shown
exactly as the edition gives them rather than split by guesswork.

## Rebuild

```sh
pip install vidyut==0.4.0
python3 - <<'PY'
from vidyut import download_data; download_data('/root/vidyut-0.4.0')
PY
python3 tools/fetch_sutras.py           # sūtra citation text (cached; needs network once)
python3 tools/build_paradigms.py        # regenerate public/data/
python3 tools/build_paradigms.py --check
python3 tools/verify_data.py            # what CI runs before deploy
```

## Deploy

Push to `main` → GitHub Action runs `tools/verify_data.py` then
`wrangler deploy`. Worker name `sanskrithelp`; the custom domain
`sanskrit.help` stays bound to that name.
