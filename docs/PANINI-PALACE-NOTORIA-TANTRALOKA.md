Chanting Mātṛkā rows = optional **embodied drill** for Zone 1–2, not a replacement for rule work.

## 6. Bruno as compiler (not character art)

For each rule / transformation store:

```text
LOCATION  = subsystem (Gate, Temple, Forest…)
AGENT     = element that acts
ACTION    = transformation
CONDITION = when it operates
OUTPUT    = what leaves
TRACE     = 1 canonical visual · 3 examples · 1 counterexample · neighbors
```

Example sandhi:
> INPUT → CONDITION → OPERATION → OUTPUT  
> Two phonological objects arrive at the Gate; condition activates; transformed object leaves.

Over time **images fade** — the operation fires when you see an applicable form.
