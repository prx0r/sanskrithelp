# The translation protocol I'd use

For every verse, create these records:

```text
SOURCE
  Sanskrit witness/edition

TEXT
  normalized Sanskrit

PADACCHEDA
  sandhi split

MORPHOLOGY
  lemma + case/person/etc.

CLOSE
  maximally literal translation

READING
  normal English

APPARATUS
  variants / uncertain reading

TERMS
  nādiphānta
  mālinī
  śakti
  nyāsa
  etc.

RELATIONS
  phoneme
  body locus
  goddess
  geometry
  pīṭha

PARALLELS
  equivalent verse in other texts

CONFIDENCE
  text
  parse
  translation
  interpretation
```

Do **not** let an LLM translate an entire chapter and then try to audit it afterward.

Your existing protocol correctly says:

**source → segmentation → Sanskrit analysis → close draft → contextual retrieval → terminology → reading translation → audit → human edit → release.**

That's the right architecture.
