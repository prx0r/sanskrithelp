## Your nightly base practice

Use this same recording every night, inserting that night's phoneme pair. Early on, the reference audio supplies the phonemes. Later versions progressively remove it.

Sit comfortably.

Let the spine be easy rather than rigid.

Hands resting.

Eyes may close.

Do nothing with the breath. Let it breathe itself.

For a few moments, listen.

Notice the sounds already present around you.

Then notice the quieter space in which those sounds appear.

[10 seconds silence]

Tonight there are only two phonemes.

Nothing else needs to be learned.

Listen first.

### First phoneme

[PLAY PHONEME A]

Do not repeat it immediately.

Wait.

[2 seconds]

Notice that before you speak, there is already a subtle intention to speak.

The sound has not happened yet.

But somehow you know which sound is about to appear.

Do not analyse this.

Simply notice it.

[2 seconds]

Now pronounce the phoneme once, matching the reference as closely as possible.

[PHONEME A]

Feel how the mouth produces it.

Notice where the tongue, lips, palate or throat participate.

Now touch its Mātṛkā locus lightly.

[LOCUS A]

Say the phoneme again while touching the locus.

[PHONEME A]

Now stop sounding.

Keep attention at the locus.

Do not immediately produce another sound.

Listen to the fading.

Sound.

Then resonance.

Then no audible sound.

[5 seconds silence]

Now remove the hand.

Without touching the body, think the phoneme once.

Do not move the mouth.

Let the body locus become salient by itself.

[5 seconds]

If the locus appears clearly, leave it alone.

If it does not, touch the locus once, pronounce the sound once, then remove the hand again.

[5 seconds]

### The gap

Before moving to the next phoneme, notice the gap.

There is no need to fill it.

The previous phoneme has disappeared.

The next has not yet appeared.

[6 seconds silence]

### Second phoneme

[PLAY PHONEME B]

Again, do not imitate immediately.

Wait.

Notice the tiny movement toward speaking before speech begins.

[3 seconds]

Now pronounce it.

[PHONEME B]

Touch its locus.

[LOCUS B]

Pronounce it again while touching.

[PHONEME B]

Stop.

[5 seconds silence]

Remove the hand.

Think the phoneme silently.

Let its locus answer.

[5 seconds]

### Pair

Now hear the first phoneme internally.

Let its locus appear.

[3 seconds]

Let its locus appear.

[3 seconds]

First.

[3 seconds]

[3 seconds]

Second.

[3 seconds]

### One more circuit

[3 seconds]

Say it.

[3 seconds]

Touch the second locus.

Wait until the phoneme comes to you.

[3 seconds]

Say it.

[3 seconds]

Hands rest again.

Notice the simple silence after the practice.

[20 seconds]

Practice complete.

## The actual syllabus

I wouldn't measure progress by days. **Advance by capability.**

| Checkpoint | What changes | Test before advancing |
|---|---|---|
| **0 · Sound** | Learn clean pronunciation + body locations | Can reproduce each learned phoneme accurately |
| **1 · Navigate** | Remove reference audio | Random phoneme → correct locus; random locus → phoneme |
| **2 · Evoke** | Remove physical touch | Hearing/thinking phoneme makes its locus immediately salient |
| **3 · Internalize** | Remove overt pronunciation | Silent phoneme ↔ body locus works in both directions |
| **4 · Random access** | Break alphabetic dependency | Can jump `ma → ṛ → kha → ṣa` without mentally traversing sequence |
| **5 · Sṛṣṭi / apyaya** | Run the whole architecture | Full sequence forward and backward without aids |
| **6 · Collective field** | Stop serially hopping | Hold a whole varga/region, eventually the body-map, as one configuration |
| **7 · Uccāra** | Attend to sound arising | Clearly perceive intention → arising → sound → fading → silence |
| **8 · Mālinī** | Install a second configuration | Mātṛkā and Mālinī maps remain distinct and navigable |
| **9 · Operators** | Bring in Pāṇini/Bruno | Manipulate phoneme classes and transformations without destroying the base map |
| **10 · Dissolve scaffold** | Geometry becomes optional | Relations remain available without deliberately visualizing body/wheel |

### Checkpoint 1 is your first real exam

No audio.

Eyes closed.

Someone—or the app—asks randomly:

**“gha.”**

Your attention should go to **right fingers** immediately.

Then:

**“left eye.”**

`ī` should appear.

Then:

**“blood.”**

`ra`.

Not:

> “Okay, ka shoulder, kha arm, ga hand… therefore gha fingers.”

That's still sequential memory.

The checkpoint passes when it becomes **direct addressing**.

I’d aim for perhaps **45/50 correct with roughly one-second access** before treating the map as installed.

## Checkpoint 2: make the body answer the sound

This is where it starts becoming more interesting.

Play:

**ma**

without telling yourself “heart.”

Does the heart region become salient?

Play:

**ka**

Does the right shoulder appear?

The locus doesn't need to literally tingle. We're not training hallucinations. You're testing whether **attention is automatically recruited to the coordinate**.

Then invert it.

Touch the heart.

Can `ma` arise without searching?

The point is to create a bidirectional association:

**sound ⇄ body**

rather than:

**sound → verbal answer → body**.

## Checkpoint 3: completely silent Mātṛkā

Now remove spoken sound.

Think:

**ma**

but don't subvocalize it deliberately.

Heart.

Think:

**ī**

left eye.

Eventually you can run the entire map silently.

This is an important threshold because MVT 2.22 immediately follows the corporeal means by discussing contemplation of a reality that is **beyond utterance**. [Sanskrit & Trika Shaivism](https://www.sanskrit-trikashaivism.com/index.php?c=en%2Fmalinivijayottaratantra-chapter-2-trika-scriptures-non-dual-shaivism-of-kashmir%2F831\&utm_source=chatgpt.com)

I would not pretend you're thereby “doing Śāktopāya.” But pedagogically the transition is elegant:

**audible sound → imagined sound → pre-verbal knowing.**

## Checkpoint 4: destroy the chain

This is a Bruno principle as much as a Sanskrit one.

Sequential memorization is useful initially:

`a ā i ī u ū...`

But it can become a crutch.

So once you know the map:

**randomize everything.**

`ṣa → thigh → au → right nails → blood → gha → mouth → ṇa`

The system gives you coordinates; you need to be able to **teleport**, not just walk the road.

This is also why the wheel we built should have random mode.

## Checkpoint 5: creation and withdrawal

Now we finally exploit something **explicitly present in TĀ 15**.

Abhinavagupta says these installations can be related to **sṛṣṭi** and **apyaya**—manifestation and withdrawal. [Sanskrit & Trika Shaivism](https://www.sanskrit-trikashaivism.com/en/tantraloka-15a-trika-scriptures-non-dual-shaivism-of-kashmir/879?utm_source=chatgpt.com)

Training version:

**Sṛṣṭi**

`a → ā → i ... → kṣa`

The phonemic body progressively appears.

Then:

**Apyaya**

`kṣa → ha → sa ... → a`

It progressively resolves.

At first this is merely **reverse recall**.

Later it becomes visualization:

> the articulated body appears through differentiation and then contracts back.

That distinction matters: learn the mechanics first; interpret it metaphysically later.

## Checkpoint 6: collective Mātṛkā

TĀ 15 also explicitly permits working with the letters **collectively** rather than only one at a time. [Sanskrit & Trika Shaivism](https://www.sanskrit-trikashaivism.com/en/tantraloka-15a-trika-scriptures-non-dual-shaivism-of-kashmir/879?utm_source=chatgpt.com)

Start with one varga.

Instead of:

`ka → kha → ga → gha → ṅa`

one after another, hold:

**the entire right-arm ka-varga**.

Five locations.

Five phonemes.

One structure.

Then:

**all sixteen vowels = face/head field.**

Then both arms.

Then legs.

Eventually:

> **the complete Mātṛkā body is available simultaneously.**

This is probably when the subtle-body “pegboard” stops feeling like fifty flashcards and starts becoming a **field**.

## Checkpoint 7: the uccāra lessons

Only once pronunciation is automatic would I really foreground this.

Take one phoneme—preferably a sustained vowel initially.

For example:

**ā**

Then observe:

**silence**
→ something intends `ā`
→ breath participates
→ articulation organizes
→ `ā` becomes audible
→ vibration is heard
→ it fades
→ silence.

Do not hold your breath or manufacture long pauses.

If there is a natural pause, notice it.

The interesting object is no longer merely **ā**.

It is the entire event:

> **how does an unspoken possibility become an audible phoneme?**

That fits the direction of TĀ 5 far better than merely learning esoteric correspondences.
