> Source: owner/product review 2026-10-05 on `/memory/bruno-wheels/`

## Diagnosis

Good components exist (varṇamālā place×manner, De umbris syllables, five-ring scenes, nyāsa rays) but wheels still behave like **selectors**:

> rotate → reveal information → remember it

Missing unlock:

> **state → apply operator → predict → world changes → inspect error → internal model updates**

Varṇamālā is strongest because it has a **real invariant transformation space**: `place × manner → phoneme`.

Generic five-ring scenes generate memorable nonsense but are not **computing Sanskrit**.

## Target product

A **Sanskrit simulator** that Bruno helps internalize — not five interesting wheels.

Four modes only:

| Mode | What you do |
|------|-------------|
| **INHABIT** | Enter the Sanskrit world; navigate known structures |
| **DECOMPILE** | Given real Sanskrit, discover how it works |
| **GENERATE** | Start from meaning/operators; produce Sanskrit |
| **PLAY** | Mutate objects; discover which transformations are legal |

Endgame loop:
- Night: ENTER TONIGHT'S WORLD (Stonedoorway) — imaginal/audio of nodes activated today
- Morning: reconstruct them cold in sanskrithelp

## Core upgrades

### 1. Live Sanskrit objects, not vocabulary lists

Example for *asato mā sad gamaya*:

```text
surface: asato mā sad gamaya
hidden:  asataḥ + mā + sat + √gam + ṇic + loṭ 2sg
semantic: SOURCE · DESTINATION · EVENT · CAUSE · COMMAND
boundaries: ḥ+m → o m · t+g → d g
```

Wheels orbit **that object**. User predicts → Pāṇini resolves → world changes.

### 2. Operators as global Bruno images (basis set)

One image per operator, not 50 mnemonics:

| Operator | Imaginal operation | Manifestations |
|----------|-------------------|----------------|
| Aspiration | wind explosion | k→kh, g→gh, c→ch |
| Voicing | vibration/illumination | k→g, kh→gh, t→d |
| Nasalization | route opens to nasal chamber | k→ṅ, t→n, p→m |

Learn the **transformation once**. Mind learns a **basis set**.

Phoneme = point in latent space: PLACE + VOICE + ASPIRATE + NASAL. Generate dental+voiced+asp → dh should **emerge**.

### 3. Morphology as transformation physics

√gam as moving entity. Operators change the invariant:

- ā- → direction/orientation
- ṇic → another agent responsible
- kta → resultant state
- ktvā → temporal past ("having gone")
- tumun → purposive future ("to go")

Morphology = transformations of an invariant, not terminology.

### 4. Pāṇini as invisible physics engine

User manipulates objects. Pāṇini decides what is allowed.

Three outcomes:
- **Valid** — world transforms
- **Conditionally valid** — "Something about this environment permits the operation. What?"
- **Invalid** — transformation fails → "Why didn't this operator fire?"

Grammar study = reverse engineering a machine.

### 5. Sandhi Collision Mode

Two words approach. Predict boundary. Collide. Sound plays before/after. Drag another initial consonant. Acquire **boundary intuition**.
