How to read this

Gold figure = Mātṛkā limb map (Tantrāloka 15).

  • Head/face — all 16 vowels (crown, forehead, mouth, eyes, ears, nostrils, cheeks, teeth, lips, tongue)
  • Right arm — ka kha ga gha ṅa (shoulder → fingers)
  • Left arm — ca cha ja jha ña
  • Legs — ṭa-varga right · ta-varga left
  • Torso — pa pha ba bha ma=heart
  • Bottom band — deep constituents (skin → generative)

Touch + chant each locus. Mouth decides the sound. Locus decides the install.

How to read this

Green figure = Mālinī map (Mālinīvijayottaratantra 3.37–41).

  • Order runs na → pha (bhinna-yoni — vowels mixed with consonants)
  • ka-varga = teeth (not shoulders — that’s Mātṛkā)
  • pa = heart (Mātṛkā heart letter is ma)
  • na = crown flame · da/pha = feet

Use this only after Mātṛkā order feels automatic.

Same phoneme, different map

Don’t blend maps. One primary per night. Yoginī names vary across sources; body loci from MV 3.37–41 are the stable Mālinī core.
