# Sanskrit × Bruno Memory Wheels

A practical first implementation of the system:

**sound → personal binding → combinatorial manipulation → Pāṇinian validation → verse compilation → StoneDoorway export**

## Start in 30 seconds

Open:

`standalone/index.html`

No server is required. It saves personal associations in browser `localStorage`.

Then use the five wheels:

1. **Varṇa Formation** — place × manner → real consonant.
2. **Bruno Five-Ring Encoder** — personal agent/action/ensign/attribute/circumstance scene.
3. **Dhātu Operator** — root × prefix × morphology × person × number; prediction-first.
4. **Kāraka Scene** — semantic roles around an event.
5. **Verse Compiler** — sound → boundary → morphology → relation → embodied binding → recall.

Use **Export StoneDoorway JSON** to save the current internal world.

## SanskritHelp installation

Copy the contents of `sanskrithelp_overlay/` into the repo root, preserving paths.

Then visit:

`/learn/bruno`

The component has no new npm dependencies.

The overlay does **not** overwrite SanskritHelp's current grammar data. That is intentional because the current pratyāhāra/dhātu metadata needs an accuracy audit first.

## Recommended first practice

### Days 1–3
Use **Varṇa Formation** only:
- choose one place,
- rotate through all five manners,
- pronounce each sound,
- give it a personal colour/body/rhythm only after articulation is stable.

### Day 4 onward
Take one short Sanskrit verse.
- shadow it,
- write it,
- decompile one phenomenon,
- use a wheel only for that phenomenon,
- predict before revealing,
- export tonight's small set to StoneDoorway.

The goal is not to remember the wheel. The goal is for the wheel to disappear into direct Sanskrit recognition.
