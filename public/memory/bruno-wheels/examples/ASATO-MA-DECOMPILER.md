# First verse laboratory — असतो मा सद्गमय

**Sound first**

`asato mā sad gamaya`  
`tamaso mā jyotir gamaya`  
`mṛtyor mā amṛtaṃ gamaya`

## Discoveries to install

1. **√gam** — persistent motion-event.
2. **ṇic causative** — `gamayati`, "causes to go / leads".
3. **2nd singular imperative** — `gamaya`, "lead / cause to go".
4. **sat + gamaya → sad gamaya** — final `t` voices before `g`.
5. **asataḥ + mā → asato mā** and **tamasaḥ + mā → tamaso mā** — visarga transformation.
6. **mṛtyoḥ + mā → mṛtyor mā** — visarga represented as `r` in this environment.
