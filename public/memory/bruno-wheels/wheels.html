How to use De umbris for Sanskrit

  1. Pick syllables that form a real Sanskrit word (or a phoneme drill sequence).
  2. For each syllable, choose one image that teaches its property (not fifty).
  3. Compose one scene: agent + action + ensign + circumstance.
  4. Place that scene on a nyāsa locus (from the body map).
  5. Replay audio cycle → say the word → feel the loci.

Example Bruno logic: NU + ME + RA + TO + RE → one composite image, not five flashcards.

Five concentric rings (De umbris large wheel): agent · action · ensign · attribute · circumstance. Spin each ring, then compose one scene and bind it to a phoneme/locus.
