# Mātṛkā Brunonian Wheel

Standalone SVG volvelle for Sanskrit Mātṛkā study.

Open `index.html` directly, or run `python3 -m http.server 8000`.

Rings: VARṆA · ARTICULATION · NYĀSA · DHVANI · IMAGO. Each ring rotates independently and snaps. IMAGO persists in localStorage. DHVANI is a mnemonic layer, not a textual claim from Abhinavagupta.

Provenance: NYĀSA loci follow TĀ 15.118–119 verse-literally (hand/fingers/nails, hip). The site TĀ 15 apparatus tables read elbow/wrist/fingers, buttock — both recorded in `../canonical/TA15_NYASA.md`; `integrated.html` shows both per phoneme. ARTICULATION is modern Sanskrit phonetics, not Abhinavagupta's *karaṇa* (his sevenfold practice, guru-taught). Pacing/study-sets are our pedagogy.
