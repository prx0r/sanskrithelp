## 1. Schmidhuber 2009 — algorithmic theory of beauty / curiosity

| | |
|--|--|
| **Title** | Simple Algorithmic Theory of Subjective Beauty, Novelty, Surprise, Interestingness, Attention, Curiosity, Creativity, Art, Science, Music, Jokes |
| **Author** | Jürgen Schmidhuber (TU Munich / IDSIA) |
| **Venue** | Journal of The Society of Instrument and Control Engineers (SICE) 48(1), 2009 |
| **DOI** | https://doi.org/10.11499/sicejl.48.21 |
| **Article** | https://www.jstage.jst.go.jp/article/sicejl/48/1/48_21/_article |
| **PDF** | https://www.jstage.jst.go.jp/article/sicejl/48/1/48_21/_pdf/-char/en |
| **Local** | `deitybody/corpus/references/schmidhuber_2009_beauty.md` (notes) · fetch PDF on demand |

### Core claim (from abstract)

Data becomes **temporarily interesting** to a self-improving, computationally limited observer when they learn to **predict or compress** it better — that is subjective “beauty.”

**Curiosity** = desire to create/discover non-random data that allows **compression progress** (regularity not yet known).

**Interestingness** = first derivative of compressibility — steepness of the learning curve.

Motivates: exploring infants, mathematicians, composers, artists… and recent AI systems.

### Why Stonedoorway keeps it

| Link | Use |
|------|-----|
| Guide / preset design | What makes a mix “interesting” vs boring: not novelty alone, but *learnable structure* |
| Night journeys | Threshold / deep-sleep phases should **compress** sensory input, not flood it |
| Memory / Bruno stack | Combinatorial wheels = deliberate compression of phonetic constituents into one image |
| Thesis roadmap | Dream threshold as *interestingness* maximization after waking — careful, speculative |

**Claim policy:** analogy / research inspiration only. Not a medical or neuro claim. No Hz doctrine.

## Alignment with Abhinavagupta vs Bruno (honest)

### Schmidhuber × **Bruno** — **strong structural analogy**

| Schmidhuber | Bruno / Sturlese De umbris |
|-------------|---------------------------|
| Compress data better → beauty | Encode foreign syllables in rings → one vivid composite image |
| Interestingness = learning-curve slope | Wheel rotations that *reveal* new regularities when spun |
| Curiosity seeks non-arbitrary structure | Practitioner fills empty cells with images that **teach** the phonetic feature |
| Computationally limited observer | Memory palace = finite loci; must compress |

Bruno’s wheel **is** a compression device: NU+ME+RA+TO+RE → one scene, not five cards.
That is the same *move* Schmidhuber formalizes — **not historically connected**, but the engineering is parallel.

**Fit for stonedoorway/sanskrithelp Memory:** use as a **design language** for Guide, presets, and Bruno wheels — “make the next mix/image compress what you already know.”

### Schmidhuber × **Abhinavagupta** — **weak / different domain**

| | |
|--|--|
| **Schmidubner** | Information theory of a limited learner: beauty = compression progress |
| **Abhinavagupta (TĀ / PTv)** | Ontology of consciousness: śabdarāśi, Mātṛkā/Mālinī as powers of awareness, nyāsa as entextualisation, aham as ground, pratyabhijñā as recognition |

There is a **loose poetic parallel**, not a doctrinal one:

- **Laya** = reabsorption of emitted into source (Goswami/Trika) *sounds like* compression toward a ground.
- **Mātṛkā order → automatic → Mālinī reconfiguration** = once a coordinate system is learned, you can permute it — a learning-curve story.
- **aham contraction** (a…kṣa → aham) = differentiation reabsorbed — not algorithmic compression.

**But:** Abhinavagupta is **not** claiming consciousness is a compressor maximizing interestingness. The endpoint is **recognition** (powers are expressions of awareness), not a learning-curve derivative.

**Fit for deitybody:** do **not** make Schmidhuber the OS. Optional footnote in memory-engine docs only.

### QRI 4D × **Bruno** — **moderate metaphor**

| QRI | Bruno |
|-----|-------|
| Higher-D structure projected into 3D view | Five concentric rings projected into one imaginal scene |
| Interpolate matrix 1→2 | Rotate rings between configurations |
| Train visual intuition | “Dilute the printed page into an immense space” (De umbris) |

Same *projection + rotation + intuition-training* pattern. Useful for **how** wheels feel, not for **what** Sanskrit phonemes are.

### QRI 4D × **Abhinavagupta** — **weak / avoid overclaim**

- QRI: higher-D geometry as consciousness research demo.
- Trika: multi-layered **coordinate overlays** (phonemic, sensory-deity, prāṇic, tattvic) — not Euclidean 4D.
- Flood + our locks: body maps are tradition-specific entextualisation, **not** modern geometry of qualia.

**Fit:** Stonedoorway night *visual* exploration only. Never merge into Mātṛkā/Mālinī body maps.
